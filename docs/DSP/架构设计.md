# v2 DSP 架构设计

配套：《[制作思路-音频信号](../../docs/DSP/制作思路-音频信号.md)》《[Pultec-SSL-复刻路线图](../../docs/Pultec-SSL-复刻路线图.md)》

> 本文件是**实现前的契约**。v1 的教训是参数映射散落在 UI 脚本里、
> 用 `setAttribute(band*5+param)` 这种数字契约，导致两个钮写同一个参数
> 也无人察觉。所以这次先定契约，再写实现。

---

## 1. 信号流

```text
输入 L/R
  │
  ├─→ [Pultec 链]  EQ → 饱和(Tanh+偏置) → 增益 gP
  │
  ├─→ [SSL 链]     EQ → 饱和(Atan) → 增益 gS
  │
  ├─→ [Bleed 支路] 饱和 → 固定小增益 gB      ← 不受 PARALLEL 影响，常开
  │
  └────────────→ [求和] → [输出校准] → 输出 L/R
```

**PARALLEL 交叉（等增益）**

| 值 | 含义 | gP | gS |
|---|---|---|---|
| 0.0 | 全 Pultec | 1.0 | 0.0 |
| 0.5 | 各半 | 0.707 | 0.707 |
| 1.0 | 全 SSL | 0.0 | 1.0 |

> **方向约定（不可违反）**：`0 = 左/Pultec`，`1 = 右/SSL`。这是用户明确要求，
> v1 曾因方向写反返工。

**三条不可违反的约束**

1. **谐波永不真旁路** —— 用户按 Bypass 只是把 wet 置 0，饱和器仍在跑；
   另有 `gB` 固定谐波支路常开。唯一的真旁通是 DAW 的插件开关。
2. **Gain Staging** —— 输入多少 dB，输出尽量保持多少 dB。全程 ≈ 0 dB 通过。
3. **不加输出补偿推子** —— 响度偏移要修链路本身（Autogain / 交叉曲线 / 校准值），
   而不是拿一个 makeup 增益盖住。

## 2. 滤波器选型决策

这是整个 DSP 的地基，先定死。

| 用途 | 方案 | 理由 |
|---|---|---|
| **Pultec LF/HF 搁架** | **WDF**（BSD-3 的 `chowdsp_wdf` 做框架，电路按公开分析自己搭） | 无源 LC 网络的搁架曲线与 biquad 差异明显；Pultec 的"大线条"正来自此 |
| **Pultec HF 钟形 + 带宽** | WDF 或 RBJ peaking（先 RBJ，听感不足再换） | 带宽控制是连续 Q，RBJ 足够 |
| **SSL LF/HF 搁架** | **高阶搁架**（Orfanidis 设计或搁架 + 微 peaking 叠加） | 标准 biquad 搁架**做不出** SSL 292 的 overshoot/undershoot |
| **SSL LMF/HMF 钟形** | **RBJ peaking + 比例 Q** | 比例 Q 是 SSL 灵魂，见 §3.3 |
| **输出/输入缓冲的高通** | 一阶/二阶高通 | 去掉直流与次声 |

**为什么不全用 WDF**：WDF 的强项是非线性与无源网络建模，
对有源运放反馈型 EQ（SSL 那套）并不占优，反而更难做比例 Q。
**分工使用**比"全都 WDF"更务实。

## 3. 音色规格

### 3.1 Pultec EQP-1A

| 段 | 类型 | 频率 | 增益范围 | 备注 |
|---|---|---|---|---|
| LF Boost | 搁架 | 20 / 30 / 60 / 100 Hz | 0 … **+13.5 dB** | |
| LF Cut | 搁架 | 20 / 30 / 60 / 100 Hz | 0 … **−17.5 dB** | |
| HF Boost | **钟形** | 3 / 4 / 5 / 8 / 10 / 12 / 16 kHz | 0 … **+18 dB** | 带 **Bandwidth**（Q 可调） |
| HF Cut | 搁架 | 5 / 10 / 20 kHz | 0 … **−16 dB** | |

**低频魔术技（必须实现）**：同时 Boost + Cut 同一频率时，曲线呈
**~80 Hz 隆起 + ~200 Hz 舀空**。成因两条，缺一不可：

1. **Boost 的实际增益略大于 Cut**（不是简单抵消）
2. **两者中心频率有偏移**（不是完全重合）

> 实现要点：Boost 与 Cut 用**独立的滤波器实例**，各自有微偏的中心频率；
> 不要图省事用一个滤波器的双向增益，那样只会得到一条平线。

**THD 低（几乎是干净的通路）** —— 不要给它塞重饱和，它会立刻显"脏"。

### 3.2 SSL 4000 G (292 "Pink Knob")

| 段 | 类型 | 频率范围 | 增益 |
|---|---|---|---|
| LF | 搁架 | 30 – 450 Hz | ±17 |
| LMF | 钟形 | 200 – 2500 Hz | ±15，带 **÷3 开关** |
| HMF | 钟形 | 600 – 7000 Hz | ±15，带 **×3 开关** |
| HF | 搁架 | 1.5 – 16 kHz | ±17 |

**本插件决策**：按路线图**不加 HPF/LPF**（决策 #5）。

### 3.3 比例 Q（SSL 灵魂，不能省）

**增益越大，Q 越窄**；增益越小，Q 越宽。

```
Q_eff = f(|gain_dB|)
  参考：gain = 0      → Q ≈ 0.1   （很宽、自然）
        gain = ±20    → Q ≈ 3.5   （集中、有针对性）
```

**先用线性拟合，实测后再修**：

```
Q_eff = Q_min + (Q_max − Q_min) * clamp(|gain_dB| / 20, 0, 1)
   Q_min = 0.1，Q_max = 3.5
```

> 也可用用户手动 Q 旋钮与比例 Q **相乘或取中**——这点待定，见 §7 待决。
> 这是区分"像 SSL"与"只是普通参量 EQ"的关键，必须做。

### 3.4 搁架 overshoot/undershoot（SSL 292 特征）

292 的 HF/LF 搁架比 E 系列更陡，且在转折频率处有独特的
**提升前小凹陷 / 衰减前小凸起**。

实现方式（择一，按实现难度递增）：
1. 搁架 biquad **叠加一个微小的反向 peaking**（最简单，先试这个）
2. Orfanidis 高阶搁架设计
3. 级联多个 biquad 逼近

> 参考图 `equi_V24_Temp.png` 与 `SLP_538_EQ_Manual` 可用于核对曲线形状。

### 3.5 非线性（"即使 EQ 平直也好听"的来源）

| 链 | 波形 | 目标谐波 | 备注 |
|---|---|---|---|
| Pultec | `tanh()` + **Bias** | 2 次（偶次）为主 | 管推挽 + 变压器，软拐点 |
| SSL | `atan()` | 3 次 + 5 次（奇次） | 运放削波，硬拐点 |
| Bleed | `tanh()` | — | 固定小电平 |

**Anti-aliasing 策略**

- 非线性一律在**过采样域**内运行（至少 4×）
- 优先用 **ADAA（antiderivative anti-aliasing）**：对已知波形函数可解析求出原函数，
  成本低、效果明显
- JUCE `dsp::Oversampling` 负责上下采样（等研究结论确认后定具体配置）

**Autogain** —— 饱和层必须带自动增益，做到"加染不加响"，否则违反 §1 约束 2。

## 5. 测试与验收

| 测试 | 方法 | 判据 |
|---|---|---|
| **频率响应** | Bertom EQ Curve Analyzer 2 扫频 | 各段曲线与规格表 §3 一致；低频魔术技呈 80 凸 / 200 舀 |

## 9. 调研带来的三条关键修正

> 这一节推翻了本文件初稿里的两个方案，实现时以本节为准。

### 9.1 ★ 搁架 overshoot：用 RBJ 公式 + 把 Q 提到 1/√2 以上

初稿写「搁架 + 叠微 peaking」或「Orfanidis 高阶搁架」，**都属绕远**。数学上的正解：

RBJ 搁架的模拟原型分母是二阶多项式：

- `Q ≤ 1/√2 ≈ 0.7071` → 极点为实数/临界阻尼 → **幅频单调，无过冲**
- `Q > 1/√2` → 出现共轭复极点 → **越靠近虚轴过冲越大**
- 而 `S = 1`（文档所称"保持单调的最陡搁架"）恰好对应 `Q = 1/√2`

**即 `S=1`（最陡单调）⟺ `Q=1/√2` ⟺ 临界阻尼。反推：只要把搁架 Q 取到 1/√2 以上，就得到带过冲的搁架，Q 是唯一控制量。**

落地：

| 用途 | 搁架 Q |
|---|---|
| SSL **G** 系列风味 | **1.0** |
| SSL **E** 系列风味 | **1.45** |
| 普通 bell 模式 | 0.71 |

⚠️ **不要用 `juce::dsp::IIR::Coefficients::makeLowShelf/makeHighShelf` 直接做 SSL 搁架**
——其默认行为对应单调搁架，**表达不出故意的过冲**。自己按 RBJ 公式写，Q 作为参数传入。

### 9.2 ★ SSL 中频用 TPT/ZDF 状态变量滤波器，不用直接 I 型 biquad

```
g  = tan(π f / fs)
k  = 1 / Q
a1 = 1 / (1 + g(g + k))
a2 = g · a1
```

理由：**零延迟反馈、系数预弯无频率弯曲、调制友好**。比例 Q 是连续变化的参数，
ZDF SVF 在参数扫动时更稳、更适合平滑。这也是第三方 SSL 实现采用的同一结构。

**比例 Q 的诚实结论**：SSL 官方**从未公布**解析式，公开检索**没有**可靠来源。
第三方那个二次式（`Q = Q_base·(1.2 + norm²·2.8)`）只是听感拟合。

→ **结构上用单调映射 `Q = f(Q_旋钮, |增益dB|)`，系数靠测量反推 + 听测标定，
不要把任何第三方的具体系数当"正确值"。**

### 9.3 ⚠️ ×3 / ÷3 降级为「待验证实验」

检索到的只有论坛转述，**没有可靠来源**。**在拿到 SSL 官方手册前，不要把 ×3÷3
写进规格**（本文件 §3.2 中的相关条目据此降级）。

### 9.4 ★ Pultec 低频魔术技：忠实建模 WDF 会自然出现

**这是本次最有价值的结论。** 论文核验：手册虽不建议同时 Boost 与 Cut 同一频率，
但**两条曲线本身落在略微不同的频段上**，同时施加即得「80 凸 + 200 舀」。

→ **这是真实电路行为的自然结果**。因此：

- 走 WDF 忠实建模 → **魔术技自动出现**，不需要额外特技
- 用两个独立 biquad 去"凑" → 很难标准化、也难以做准

**这解释了 v1 在 HISE 里用 CurveEq 做低频魔术技为什么卡住。**

### 9.5 ★ Pultec WDF 树（可省掉 R-Type）

论文的关键简化：**因为不需要匹配真实输入/输出阻抗，作者移除了电路的输入与输出电阻并相应调整元件值** → 整个无源 EQ 级**只用串联/并联 adaptor 即可建模，完全不需要 R-Type adaptor**。实测 R-Type 版慢 75%。

```
IdealVoltageSource（树根）
└─ S3 = Series(S2, J)
   ├─ S2 = Series(S1, pEFGHI)
   │  ├─ S1 = Series(RBoostHi1, pCD)
   │  └─ pEFGHI = Parallel(sEFG, sHI)
   │     ├─ C = Series(SCLc(Series C1,L1), SRQ(Series RQ,RQ_offset))   ← 谐振 RLC
   │     └─ H = Parallel(LoFreqC1, RCutLo)                             ← 低频衰减搁架
   └─ J = Parallel(RBoostLo, LoFreqC2)                                 ← 低频提升搁架
```

**关键建模模式：电位器 = 两个可变电阻的分压。**
所有增益旋钮 = 把固定上限电阻 `R_MAX` 拆成 `(1−g)·R_MAX` 与 `g·R_MAX`
串在树的不同分支上，`g ∈ [0,1]`（初值取 `0.00001` 而非 0，避免除零）。

**元件常量**（来自论文实现，作为起点；后续按实测微调）

| 常量 | 值 |
|---|---|
| `RBOOSTHI_MAX` / `RQ_MAX` / `RQ_OFFSET` | 12 kΩ / 3.9 kΩ / 390 Ω |
| `RCUTHI_MAX` / `RBOOSTLO_MAX` / `RCUTLO_MAX` | 1 kΩ / 8.2 kΩ / 110 kΩ |
| `RATIO_L1_C1` | 12e6（`C1 = √(1/(ratio·ω²))`，`L1 = ratio·C1`） |
| `R1` / `R2` / `R3` | 91 Ω / 1 kΩ / 10 kΩ |
| 低频档 LoFreqC2 | 20Hz→2.2µF、30→1.1µF、60→560nF、100→330nF（`LoFreqC1 = C2/30`） |
| 高频衰减 CHiCut | 5k→270nF、10k→135nF、20k→68nF |

输出：`(−voltage(J) + voltage(R3)) × 15.4882`（固定系数补偿插入损耗，与采样率无关）。

**⚠️ 三个必须避开的原实现缺陷**（我们不复刻它们）：
1. 过采样倍率切换在 `processBlock` 末尾**重建 FIR 链** → **音频线程里做重分配，非实时安全**
2. 逐样本 `setSample/getSample`（低效）
3. 旁通时**未做过采样延迟对齐**

> 另注：HF Boost 是**谐振 RLC，不是简单 peaking**。论文 Table 3 显示
> **HF Boost 的 RMSE 比其余段高三到四个数量级**（48k 时 1.40 vs 其余 ~1e-2），
> 是最难做准、最依赖过采样的一段。

### 9.6 非线性实现定型

| 项 | 决定 |
|---|---|
| **过采样** | **坚持用 JUCE `dsp::Oversampling`**（已是依赖、有完整延迟上报）；**不要**为"可能更好"引入 libsamplerate/r8brain（那是通用重采样器，不是半带过采样器） |
| **ADAA** | ⚠️ `chowdsp_utils` 里唯一提供 ADAA 的模块是 **GPLv3** → **自行实现**。一阶核心极简：<br>`y[n] = (F1(x[n]) − F1(x[n−1])) / (x[n] − x[n−1])`，`x[n]≈x[n−1]` 时退化为 `f((x[n]+x[n−1])/2)`<br>`tanh` 的 `F1 = ln(cosh x)`；含 `+a·x²` 的不对称波形同样有初等原函数 → 几十行即可，比引 GPL 依赖干净 |
| **ADAA 定位** | 最佳用法是**配合低倍过采样（如 2×）**，不是取代过采样（DAFx-16 原文） |
| **不对称波形** | 优选「**分段多项式**，正负半周不同曲线」（偶次谐波最多，"管味"主要来源）。数学事实：**奇函数波形只产生奇次谐波，要出偶次必须有偶函数分量** |
| **DC 阻断** | 不对称必然产生直流 → **前后各一个一阶 DC 阻断器**（`y = x − x1 + 0.999·y1`），成本极低，必加 |
| **Koren 管模型** | **现在不做**。本项目是 EQ 风味产品不是管放模拟器；不对称 waveshaper + ADAA + 2× OS 已能给出可辨的偶次染色，而 Koren+WDF 管级会带来巨大算力、与 EQ 级的耦合稳定性问题、以及大量实测标定 |

## 10. 两条架构级前置风险（必须现在处理）

### 🚩 风险 1：并行混合 × 过采样的延迟对齐

引入过采样后，**两条并行支路的延迟必须严格相等**，否则 PARALLEL 一拧就出现
**梳状滤波 / 相位抵消**——用户会听成"混合时低频变薄"。叠加 JUCE 非整数延迟的坑更隐蔽。

**硬性要求**：

- 过采样必须开 **`useIntegerLatency = true`**
  （否则线性相位 FIR 的延迟通常非整数，直接取整会引入**分数样本相位误差**）
- **不过采样的支路（Bleed）必须插等量延迟**
- 这是**架构级要求，不是优化项**

### 🚩 风险 2：DSP 必须写在 C++ 侧，HISE 路线的能力边界

本项目已决定脱离 HISE 转纯 JUCE + CMake，因此**所有 DSP 在 C++ 里写**。
（背景：HISE 里接 C++ 只有 SNEX 与自定义模块两条路，而 `chowdsp_wdf` 大量使用
C++14 模板与 `decltype`，SNEX 极可能不支持 → 要用 WDF，纯 JUCE 是唯一现实路线。）
