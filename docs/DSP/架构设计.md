# v2 DSP 架构设计

配套：《[制作思路-音频信号](../../docs/DSP/制作思路-音频信号.md)》《[Pultec-SSL-复刻路线图](../../docs/Pultec-SSL-复刻路线图.md)》

> 本文件是**实现前的契约**。v1 的教训是参数映射散落在 UI 脚本里、
> 用 `setAttribute(band*5+param)` 这种数字契约，导致两个钮写同一个参数
> 也无人察觉。所以这次先定契约，再写实现。

---

## 1. 信号流

```text
输入 L/R
  │
  ├─→ [Pultec 链]  EQ → 饱和(Tanh+偏置) → 增益 gP
  │
  ├─→ [SSL 链]     EQ → 饱和(Atan) → 增益 gS
  │
  ├─→ [Bleed 支路] 饱和 → 固定小增益 gB      ← 不受 PARALLEL 影响，常开
  │
  └────────────→ [求和] → [输出校准] → 输出 L/R
```

**PARALLEL 交叉（等增益）**

| 值 | 含义 | gP | gS |
|---|---|---|---|
| 0.0 | 全 Pultec | 1.0 | 0.0 |
| 0.5 | 各半 | 0.707 | 0.707 |
| 1.0 | 全 SSL | 0.0 | 1.0 |

> **方向约定（不可违反）**：`0 = 左/Pultec`，`1 = 右/SSL`。这是用户明确要求，
> v1 曾因方向写反返工。

**三条不可违反的约束**

1. **谐波永不真旁路** —— 用户按 Bypass 只是把 wet 置 0，饱和器仍在跑；
   另有 `gB` 固定谐波支路常开。唯一的真旁通是 DAW 的插件开关。
2. **Gain Staging** —— 输入多少 dB，输出尽量保持多少 dB。全程 ≈ 0 dB 通过。
3. **不加输出补偿推子** —— 响度偏移要修链路本身（Autogain / 交叉曲线 / 校准值），
   而不是拿一个 makeup 增益盖住。

## 2. 滤波器选型决策

这是整个 DSP 的地基，先定死。

| 用途 | 方案 | 理由 |
|---|---|---|
| **Pultec LF/HF 搁架** | **WDF**（BSD-3 的 `chowdsp_wdf` 做框架，电路按公开分析自己搭） | 无源 LC 网络的搁架曲线与 biquad 差异明显；Pultec 的"大线条"正来自此 |
| **Pultec HF 钟形 + 带宽** | WDF 或 RBJ peaking（先 RBJ，听感不足再换） | 带宽控制是连续 Q，RBJ 足够 |
| **SSL LF/HF 搁架** | **高阶搁架**（Orfanidis 设计或搁架 + 微 peaking 叠加） | 标准 biquad 搁架**做不出** SSL 292 的 overshoot/undershoot |
| **SSL LMF/HMF 钟形** | **RBJ peaking + 比例 Q** | 比例 Q 是 SSL 灵魂，见 §3.3 |
| **输出/输入缓冲的高通** | 一阶/二阶高通 | 去掉直流与次声 |

**为什么不全用 WDF**：WDF 的强项是非线性与无源网络建模，
对有源运放反馈型 EQ（SSL 那套）并不占优，反而更难做比例 Q。
**分工使用**比"全都 WDF"更务实。

## 3. 音色规格

### 3.1 Pultec EQP-1A

| 段 | 类型 | 频率 | 增益范围 | 备注 |
|---|---|---|---|---|
| LF Boost | 搁架 | 20 / 30 / 60 / 100 Hz | 0 … **+13.5 dB** | |
| LF Cut | 搁架 | 20 / 30 / 60 / 100 Hz | 0 … **−17.5 dB** | |
| HF Boost | **钟形** | 3 / 4 / 5 / 8 / 10 / 12 / 16 kHz | 0 … **+18 dB** | 带 **Bandwidth**（Q 可调） |
| HF Cut | 搁架 | 5 / 10 / 20 kHz | 0 … **−16 dB** | |

**低频魔术技（必须实现）**：同时 Boost + Cut 同一频率时，曲线呈
**~80 Hz 隆起 + ~200 Hz 舀空**。成因两条，缺一不可：

1. **Boost 的实际增益略大于 Cut**（不是简单抵消）
2. **两者中心频率有偏移**（不是完全重合）

> 实现要点：Boost 与 Cut 用**独立的滤波器实例**，各自有微偏的中心频率；
> 不要图省事用一个滤波器的双向增益，那样只会得到一条平线。

**THD 低（几乎是干净的通路）** —— 不要给它塞重饱和，它会立刻显"脏"。

### 3.2 SSL 4000 G (292 "Pink Knob")

| 段 | 类型 | 频率范围 | 增益 |
|---|---|---|---|
| LF | 搁架 | 30 – 450 Hz | ±17 |
| LMF | 钟形 | 200 – 2500 Hz | ±15，带 **÷3 开关** |
| HMF | 钟形 | 600 – 7000 Hz | ±15，带 **×3 开关** |
| HF | 搁架 | 1.5 – 16 kHz | ±17 |

**本插件决策**：按路线图**不加 HPF/LPF**（决策 #5）。

### 3.3 比例 Q（SSL 灵魂，不能省）

**增益越大，Q 越窄**；增益越小，Q 越宽。

```
Q_eff = f(|gain_dB|)
  参考：gain = 0      → Q ≈ 0.1   （很宽、自然）
        gain = ±20    → Q ≈ 3.5   （集中、有针对性）
```

**先用线性拟合，实测后再修**：

```
Q_eff = Q_min + (Q_max − Q_min) * clamp(|gain_dB| / 20, 0, 1)
   Q_min = 0.1，Q_max = 3.5
```

> 也可用用户手动 Q 旋钮与比例 Q **相乘或取中**——这点待定，见 §7 待决。
> 这是区分"像 SSL"与"只是普通参量 EQ"的关键，必须做。

### 3.4 搁架 overshoot/undershoot（SSL 292 特征）

292 的 HF/LF 搁架比 E 系列更陡，且在转折频率处有独特的
**提升前小凹陷 / 衰减前小凸起**。

实现方式（择一，按实现难度递增）：
1. 搁架 biquad **叠加一个微小的反向 peaking**（最简单，先试这个）
2. Orfanidis 高阶搁架设计
3. 级联多个 biquad 逼近

> 参考图 `equi_V24_Temp.png` 与 `SLP_538_EQ_Manual` 可用于核对曲线形状。

### 3.5 非线性（"即使 EQ 平直也好听"的来源）

| 链 | 波形 | 目标谐波 | 备注 |
|---|---|---|---|
| Pultec | `tanh()` + **Bias** | 2 次（偶次）为主 | 管推挽 + 变压器，软拐点 |
| SSL | `atan()` | 3 次 + 5 次（奇次） | 运放削波，硬拐点 |
| Bleed | `tanh()` | — | 固定小电平 |

**Anti-aliasing 策略**

- 非线性一律在**过采样域**内运行（至少 4×）
- 优先用 **ADAA（antiderivative anti-aliasing）**：对已知波形函数可解析求出原函数，
  成本低、效果明显
- JUCE `dsp::Oversampling` 负责上下采样（等研究结论确认后定具体配置）

**Autogain** —— 饱和层必须带自动增益，做到"加染不加响"，否则违反 §1 约束 2。

## 5. 测试与验收

| 测试 | 方法 | 判据 |
|---|---|---|
| **频率响应** | Bertom EQ Curve Analyzer 2 扫频 | 各段曲线与规格表 §3 一致；低频魔术技呈 80 凸 / 200 舀 |
| **比例 Q** | 同一频率下扫不同增益，看 Q 变化 | 增益增大 Q 变窄，趋势与 §3.3 一致 |
| **搁架 overshoot** | 观察转折频率附近 | 提升前有小凹陷 / 衰减前有小凸起 |
| **THD** | 用示波器/分析器看谐波成分 | Pultec 偏 2 次、SSL 偏奇次 |
| **混叠** | 高频正弦 + 看非谐波成分 | 过采样后混叠显著低于未过采样 |
| **Gain Staging** | **null test**：旁通 vs 启用，同参数 | 电平差 **< ~0.3 dB** |
| **Runtest（关键）** | 各参数在两极值下运行 | 无爆音、无 NaN、无直流 |
| **PARALLEL 端点** | 0 / 0.5 / 1 三点 | 端点为单路 ≈ 0 dB；0.5 为等增益求和 |

> **Runtest 是 v1 没做的一项**，务必补上：参数在两极值时最容易暴露
> 滤波器的稳定性问题（尤其是比例 Q 与 WDF 在极端增益下）。

## 6. 目录结构

```text
Source/DSP/
├── Filters/          滤波器：biquad、搁架、状态变量
├── Saturation/       饱和：tanh/atan、偏置、ADAA、Autogain
├── Pultec/           Pultec 链装配（含低频魔术技）
├── SSL/              SSL 链装配（比例 Q、×3÷3、搁架 overshoot）
└── Dynamics/         RMS 测量、参数平滑
```

**与 `PluginProcessor` 的边界**：`PluginProcessor` 只负责
参数读写、总线布局、调用 DSP 链；**所有信号处理都在 `Source/DSP/` 内**，
不写在 `processBlock` 里。
