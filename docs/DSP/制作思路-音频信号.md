Plugin Architecture: "Analog Blend"
Core Concept
You're building a parallel saturation/harmonic enhancer with two distinct analog character processors — Pultec-flavored and SSL-flavored — blended together. The key design insight borrowed from the SSL 4000/9000 series is that harmonic generation happens even at zero mix (bypass), because the circuit is always "on" — only its wet signal level changes.



The "Bypass Still Adds Harmonics" Trick
This is the clever part. In the SSL 4000 console, the transformer and input stage always introduce harmonics — even when EQ is bypassed. You replicate this by:

Never truly bypassing the harmonic generators — instead, when the user hits "Bypass," you set the wet blend to 0% but leave the harmonic processor running
Then add a small fixed-level harmonic bleed (e.g. -30 to -40 dB) that is always present regardless of the mix knob
The DAW bypass (plugin power off) is the only true bypass

[Harmonic Generator] → always running
         │
         ├── [Mix Knob path] (user-controlled)
         └── [Fixed bleed ~-35dB] (always present, even at Mix=0)

Volume Compensation (Unity Gain)
This is the most technically tricky part. Since saturation adds harmonic energy, perceived loudness goes up. You have two options:
Option A — RMS Matching (Recommended)
Measure the RMS of the dry signal before processing. After processing, apply a makeup gain trim so output RMS matches input RMS. Calculate this per-block or with a short averaging window (~50ms).
Option B — Gain Reduction Lookup Table
Pre-characterize how much loudness each saturation algorithm adds at different drive levels, and compensate with a corresponding dB trim. Less CPU, slightly less accurate.



HISE-Specific Implementation Notes

Signal splitting — Use RoutingMatrix in HISE to create parallel chains. Each chain (Pultec, SSL) is a separate signal path.
Harmonic generators — Implement as ScriptProcessor nodes using JavaScript waveshaping. HISE supports custom process() callbacks.
Mix knobs — Use the built-in CC_KNOB with a linear 0–1 range feeding a Gain module on each wet chain.
Volume compensation — Implement in a ScriptProcessor after the final sum, measuring RMS with a ring buffer.
The harmonic bleed — Add a separate parallel ScriptProcessor with fixed gain, always active regardless of mix knob state.

## 🎛️ Pultec EQP-1A 的核心特点

### 一、历史与设计理念

Pultec EQP-1 由 Pulse Techniques 公司（Ollie Summerland 与 Gene Shank）于 **1951年** 在新泽西推出。它是**世界上第一台无源程序均衡器（Passive Program Equalizer）**，最初被广播电台用于"为优质节目素材添加最后的润色"。所有 Pultec 均为全手工定制，做工无可匹敌。

---

### 二、"魔法的秘密"

#### 2.1 即使 EQ 关闭，声音也能变好

信号经过 Pultec 即使不启用任何 EQ，工程师们也普遍感受到声音变得更"好听"。原因在于其**电子管推挽放大级**：

| 位置 | 使用的电子管 | 说明 |
|------|-------------|------|
| 输入级 | **ECC83 (12AX7)** 双三极管 | 推挽模式下处理平衡信号的每一半 |
| 输出级 | **ECC82 (12AU7)** 双三极管 | 驱动输出变压器 |

- 输出变压器带有**额外的反馈绕组**，能自动补偿变压器失真和部分输出负载效应
- 管子与变压器共同产生的**谐波染色**给低频增添"重量感"，同时让高频更开放

> "把任何东西经过 Pultec，即使不启用 EQ，总会增添一种低频的厚重感和高频的开阔感。" — *Vintage King*

#### 2.2 "低频魔术技"（Low-End Trick）

这是 Pultec 最具标志性的用法：**同时对同一频率进行 BOOST 和 CUT**。

虽然手册中说 Boost 和 Attenuate 不该同时使用（理论上会互相抵消），但实际上：

- Boost 控制的实际增益**略大于** Attenuate 的衰减量
- Boost 和 Attenuate 的**中心频率略有偏移**，并不是完全重合

以 **30Hz 同时 Boost + Cut** 为例，最终曲线呈现为：**80Hz附近隆起 + 200Hz附近凹陷**——形成一种类似"低频中段舀空"的曲线，极适合底鼓和贝斯。

#### 📍 第5步：关键工程技巧

1. **过采样（Oversampling）必不可少**：WDF 模型在音频采样率下可能出现数值误差，需要用 JUCE 的 `dsp::Oversampling` 类进行至少 2-4 倍过采样。

2. **非线性建模（进阶）**：基础 WDF 模型是线性的。要真正复现 Pultec 的"魔法"，还需：
   - 对电子管（12AX7/12AU7）进行**非线性建模**（如 Koren 管模型）
   - 对变压器加入**磁滞饱和**模型
   - 这可以让你实现"即使EQ关闭也能带来好声音"的谐波染色效果

3. **如果不想从头写 WDF**，还有更轻量的替代方案：
   - 直接用 **IIR biquad 滤波器**逼近 EQ 曲线（用 MATLAB 的 `yulewalk` 或 Python `scipy.signal` 做滤波器设计）
   - 加上一个**独立的饱和/谐波激励模块**模拟管放大级的染色
   - 使用**卷积/脉冲响应（IR）** 方法（但无法模拟动态非线性）

### 第 2 步：SPICE 电路仿真

这是理解模拟电路行为的关键中间环节：

- 将 292 EQ 电路导入 SPICE 仿真器（LTspice 等）
- 运行 **AC 分析**获取每个频段在不同参数下的**传递函数**
- 运行 **瞬态分析**观察非线性行为（运放饱和、电容充放电特性）
- 提取关键数据：
  - 各频段在不同增益下的实际 Q 值和中心频率偏移
  - 搁架滤波器的 overshoot/undershoot 的幅度和频率关系
  - Proportional-Q 的具体映射规律

---

### 第 3 步：数字滤波器基础设计（线性部分）

这是整个复刻的骨架，建议使用 **Biquad (双二阶) 滤波器**作为起点：

#### 3a. 中频钟形滤波器 (LMF / HMF)

```python
# 参考 RBJ Audio EQ Cookbook 的 peaking filter
# 关键：实现 Proportional-Q
# Q_effective = f(gain_db)  —— Q 随增益增大而增大

def proportional_q(gain_db, q_nominal):
    """增益越大，Q 越窄；增益越小，Q 越宽"""
    # 根据实际测量数据拟合此函数
    # SSL 292: gain=0 → Q≈0.1, gain=±20 → Q≈3.5
    return q_nominal * (1.0 + abs(gain_db) / 20.0 * some_factor)
```

#### 3b. 低频/高频搁架滤波器 (LF / HF)

- 标准 biquad 搁架滤波器**无法还原** SSL 292 的 overshoot/undershoot 特性
- 需要：
  - **高阶 IIR 滤波器**（级联多个 biquad）
  - 或使用 **Orfanidis 高阶搁架设计**
  - 或在搁架 biquad 基础上叠加一个微小的 peaking filter 来模拟过冲

#### 3c. 高通/低通滤波器

- 高通：3 阶 (18 dB/oct) Butterworth 或类似特性
- 低通：需要确认具体阶数和类型

---

### 第 4 步：非线性建模（模拟「味道」的来源）

线性滤波只完成了 50%，SSL 的声音很大程度上来自非线性：

#### 4a. 饱和与谐波失真

- 在每个 EQ 频段前后加入**软削波 (soft-clipping)** 阶段
- 建模运放饱和：使用 **tanh()** 或更复杂的 **反双曲正弦** 函数
- 模拟 **Jensen JT-115K-E 变压器**的磁滞饱和特性（如果需要复刻完整 channel strip）
- 关键参数：对称性、奇次/偶次谐波比例

#### 4b. 过采样 (Oversampling)

> **非线性处理必须在高采样率下进行，否则会产生严重的混叠失真。**

- 内部至少 **4× 过采样**（如 44.1k → 176.4k）
- 使用高质量的多相 FIR 半带滤波器进行上采样/下采样
- HQ 模式可以做到 8× 或更高

#### 4c. VCA 建模

- 输出级的 **THAT 2002T "Blue Can" VCA** 是 G Series fader 的关键
- 其非线性谐波是电平依赖的 (level-dependent)
- 可以建模为增益依赖的软削波 + 谐波发生器

---

### 第 5 步：组件容差建模 (TMT)

Brainworx 的 Tolerance Modelling Technology 是其 SSL 仿真广受好评的重要原因：

- 真实模拟电路中每个**电阻、电容的实际容差**（通常 ±5% 到 ±10%）
- 这导致每个通道的 EQ 曲线**略微不同**
- 在多个轨道上使用时，这些微小差异叠加，产生**更宽的立体声场**和**更自然的整体声音**
- 实现方式：在滤波器系数上叠加可控的随机偏移量

---

### 第 6 步：实时参数平滑与抗杂音处理

模拟 EQ 的参数变化是连续的，数字实现需要处理：

- **系数平滑**：使用一阶低通平滑（leaky integrator）对 biquad 系数进行渐变
- **状态变量更新**：参数变化时正确处理滤波器状态，避免瞬态杂音
- 考虑使用 **ZDF (Zero-Delay Feedback) State Variable Filter** 替代传统 biquad，在极端参数下有更好的稳定性

---

### 第 7 步：测试验证与迭代优化

- **频率响应对比**：使用 PluginDoctor 或手动扫频，与硬件/参考插件逐频段对比
- **null test（极性反转抵消测试）**：在相同参数下与参考对比残留信号
- **盲听 AB 测试**：组织有经验的音频工程师进行主观评价
- **性能优化**：
  - 提供 HQ (高过采样) / ECO (低延迟) 模式切换
  - 使用 SIMD 指令优化 biquad 计算
  - 对非活跃频段做处理旁路

## 总结

SSL 4000 G Series 292 EQ 的核心灵魂在于 **Proportional-Q 、×3/÷3 频率扩展、搁架 overshoot 特性**，以及贯穿信号链的**模拟非线性色彩**。复刻的关键路线可以概括为：

> **电路分析 → SPICE 建模仿真 → 传递函数提取 → 数字滤波器实现（biquad → proportional-Q + overshoot 搁架）→ 非线性层叠加（饱和+过采样+VCA）→ 容差模拟 → 测试验证**

即使是个人开发者，从实现一个 **单频段的 proportional-Q peaking filter** 开始，逐步加入搁架特性、非线性和过采样，也是一条完全可行的学习与实践路径。希望这份指南对你的复刻之旅有所帮助！
